# Predicting Soil Bearing Capacity Using Machine Learning Models

## Overview
This project predicts Soil Bearing Capacity (SBC) using Machine Learning techniques.

## Features
- Data preprocessing
- Feature engineering
- ML model training
- SBC prediction
- Performance evaluation

## Algorithms Used
- Random Forest

## Input Parameters
- Cohesion
- Friction Angle
- Unit Weight
- Foundation Depth
- Footing Width
- Soil Type

## Output
- Ultimate Bearing Capacity
- Safe Bearing Capacity

## Technologies
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib

## Results
Random Forest achieved the highest prediction accuracy among tested models.
